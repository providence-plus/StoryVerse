# 任务：为新增字段补齐当前值

> 本文件由后端在「玩家新增字段」时读取，可在 Prompt Studio 编辑，保存后立即生效。
> 玩家可能在任意轮次新增字段——第 1 轮、第 12 轮、第 30 轮都行，不存在固定轮数。

## 什么时候会用到你

玩家在 Panel Designer 里加了一个或几个**以前不存在的字段**，但角色已经有过一段剧情了。
现在需要你根据已经发生的一切，推断这些字段**此刻**应该是什么值。

## 输入

- 世界设定与规则：
  {{world_context}}

- 角色固定人物卡：
  {{character_profile_json}}

- 角色已有的字段值（这些是既成事实，**不许改动**）：
  {{existing_fields_json}}

- 本次新增字段的定义（字段键、名称、说明、类型、枚举选项）：
  {{new_fields_json}}

- 剧情摘要：
  {{summary}}

- 相关时间线事件：
  {{timeline_events}}

- 最近若干轮互动：
  {{recent_history}}

- 当前地点与在场人物：
  {{current_context}}

## 你要做什么

- 只为 `{{new_fields_json}}` 里列出的字段给值，**一个字段都不能漏，也不能多给**。
- 值必须是"这一刻"的值，不是角色刚出场时的值。如果这段剧情里发生过会改变该字段的事，要按**已经发生之后**的状态给。
- 推断要有依据：优先用时间线和摘要里的既成事实，其次用最近几轮里人物反复表现出来的倾向。证据不足时给一个保守、中性、不制造新剧情的起点值，不要凭空编一段没发生过的往事来把它填得好看。
- 值必须与该字段的 `type` 一致：`text` / `long_text` 字符串、`number` 数字、`boolean` 布尔值、`enum` 只能选预设项、`list` 数组、`key_value` 对象。
- 若新字段是"对主角的真实评价""信任程度""隐藏想法"这类内在状态，要能从已发生互动里推得出来，并在 `reason` 里点出是哪件事让你这么判断。
- **已有字段一个都不许返回，更不许改动。** 你的输出只会被写入新增的那几个键。
- **不许新增、删除、改名任何字段，不许改动字段定义。**
- 不许替玩家决定想法或补写玩家没做过的行为。

## 严格输出以下 JSON

```json
{
  "values": {
    "新字段键": "符合该字段类型的值"
  },
  "reasons": {
    "新字段键": "一句话说明依据来自哪段既有剧情；证据不足就写「证据不足，取保守起点」"
  }
}
```

- `values` 的键必须与 `{{new_fields_json}}` 完全一致。
- 只输出 JSON。后端会逐项校验类型后才写入，非法值会被丢弃，所以请一次给对。
